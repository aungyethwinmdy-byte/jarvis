### Why the standards look the way they do

They are **derived from this project's own defect history**, not from a generic checklist. `AGENT-AUDIT.md`
found 10 defects (F1–F10); rounds 12–21 of the work log found eight more. **Not one of them raised an
exception.** Four survived `check_agent.py` passing 430/430. So the standard is organised around a single
question — *if this change is wrong, will anything say so?* — and the five axes are the five ways this
project has been wrong silently.

The project had already written most of these rules down as memory entries. `CODE-REVIEW.md` turns them into
review criteria, and `review_gate.py` turns the mechanical ones into checks.

### 🔴 Finding — `actions/file_controller.py:420` — an undo path that will hang

- **Evidence.** `file_controller.py:420`, inside `_undo_copy()`:
  ```python
  if _copy.is_dir():
      shutil.rmtree(_copy)
  ```
- **Mechanism.** `_undo_copy` is the undo pushed after a **copy**, so it removes the *copy*, never the
  original — correct design. But on this machine `shutil.rmtree` is patched by the WorkBuddy trash shim
  (`_safe_shutil_rmtree → _try_trash → subprocess.run(...)`), which **deadlocks on a non-empty directory**
  and sits at ~0 CPU with no exception. `_copy` is a directory copy, so it is non-empty.
- **Consequence.** Undoing a directory copy hangs the undo worker silently. The user asks to undo and nothing
  happens, with no error.
- **Root cause.** A recursive delete API used where the environment's shim cannot complete it.
- **Confidence.** 0.85 — the shim behaviour is measured (user memory, 2026-09-23); that this specific call
  site deadlocks is inferred from it, and should be reproduced before fixing.
- **Severity.** S1 — a silent no-op on a user-visible action.
- **Suggested fix.** Route the recursive case through the same mechanism the project already uses elsewhere
  (`core/custom_voice.py:246` calls Node's `fs.rmSync`), or detect the shim
  (`"sitecustomize" in getattr(shutil.rmtree, "__module__", "")`) and fall back. **Not applied** — it changes
  the behaviour of an undo path, which the process says needs the owner's decision.
